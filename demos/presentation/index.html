Target Audience: Engineering Leads & QA Managers

The Problem

In the world of AI coding, generation is free. But trust isn't.

If an AI hallucinates the expected outcome, you end up with green builds that are actually broken.

The Solution

The OpenAPI Specification is the Single Source of Truth.

  • Generates Playwright tests via LLM.
  • Deterministically verifies assertions against the spec.
  • Catches AI hallucinations statically.

Zero to Hero Quickstart

Let's use the public Petstore API.

Initialize & Generate


# 1. Initialize
cherenkov init

# 2. Download standard Petstore spec
curl -s https://petstore3.swagger.io/api/v3/openapi.json -o petstore.json

# 3. Generate the tests
cherenkov generate --spec petstore.json --output-dir tests/ --no-repair

Validate

Run against the real, live API to find spec drift.


cherenkov validate \
  --target https://petstore3.swagger.io/api/v3 \
  --spec petstore.json \
  --fail-on-drift

The Live Case

JSONPlaceholder API (Real Production API)

Generate with Self-Healing


# Generate and fix errors automatically
cherenkov generate \
  --spec jsonplaceholder_spec.json \
  --output-dir tests-jsonplaceholder/ \
  --repair

Validate

Hitting real endpoints across the internet.


cherenkov validate \
  --target https://jsonplaceholder.typicode.com \
  --spec jsonplaceholder_spec.json
