CHERENKOV QA Recorded Sessions

These are the fully real, live terminal recordings capturing CHERENKOV in action.

1. Quickstart: Petstore API (Zero to Hero)

This session demonstrates generating Playwright tests against the standard Petstore OpenAPI spec. It runs the LLM generation locally and then validates the suite against the live `petstore3.swagger.io` server.

2. Live Case: JSONPlaceholder (Real Production API)

This session proves CHERENKOV against a completely real, public REST API. It uses `jsonplaceholder_spec.json` and targets `https://jsonplaceholder.typicode.com` without any mock servers or containers.
