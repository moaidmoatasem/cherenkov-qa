The Cherenkov testing system

Two tracks, one gate, one loop. Left is the execution scaffold — it runs whatever test lands on disk and does not care who wrote it. Right is the orchestration layer that gets an LLM to write it. Neither side is trusted alone: everything converges on the oracle, which checks behaviour against the spec, not against the model's own claims.
