# Release Notes: CHERENKOV-QA v1.2.0

**Date:** 2026-08-01

## What's New Since v1.1.2

### UX Redesign

The web dashboard was reorganized around a 5-hub information architecture — Overview, Author & Generate, Triage, Coverage & Certification, and Knowledge — replacing the prior flat navigation. Alongside the restructure:

- **Triage** moved to a Kanban board, with the "View Spec Diff" action wired to the real divergence detail.
- **Spec vs. Reality** and **Coverage & Certification** now render live data from `/api/v1/divergences` instead of hardcoded samples; the certificate panel points to the `cherenkov certify` CLI rather than a fabricated history view.
- **Test Management** is a new screen backed by real generated-test and run data, including a coverage/health trend chart.
- **Chat** now lists real prior sessions (`GET /api/v1/chat/sessions`) instead of a placeholder history panel.

### Fixed

- **Release/tag reconciliation** — `.release-please-manifest.json` and `package.json` had drifted to `1.0.0` while `pyproject.toml` and the actual tag history had already moved to `1.2.0`, and the `v1.1.1` release was tagged `v.1.1.1` (stray dot), which breaks the docs-deploy version-extraction step. Manifest and package version now match; going forward, releases should be cut through release-please rather than hand-tagged to avoid a repeat.
- Several runtime bugs surfaced by driving the app end-to-end in a real browser rather than relying on typecheck/build alone: an infinite Chat re-render loop, a missing `Depends()` wrapper causing 500s on the runs API, a non-JSON-serializable validation-error path, and duplicate React keys on the doctor/health checks list.

### Roadmap

Phase 11 (VS Code extension) and Phase 12 (GraphQL/gRPC/AsyncAPI) are complete and wired in. Phase 13 (Enterprise: SAML/RBAC/audit/org/compliance) has real backend logic wired into `cherenkov enterprise` CLI commands (post-release, #810/#824). Phase 14's Spec Guardian daemon is now reachable via `cherenkov guardian start` (post-release, #811/#823). Phase 15 (fine-tuned model) is an explicit simulation, not a real training pipeline. Phase 16 (platform/marketplace) is mostly stub data. See the [project issue tracker](https://github.com/moaidmoatasem/cherenkov-qa/issues) for current status per item — an earlier note here claimed all of Phase 11-16 was complete; that was inaccurate and has been corrected.
