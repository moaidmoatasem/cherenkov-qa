# Release Notes: CHERENKOV-QA v1.3.0

**Date:** 2026-08-02

## What's New Since v1.2.0

### Features

- **Spec Guardian CLI** (Phase 14): `cherenkov guardian start --spec <spec> --base-url <url>`
  polls every endpoint declared in the OpenAPI spec and persists drift events to the
  drift store until interrupted (SIGINT/SIGTERM). Override with repeatable
  `--endpoint METHOD:PATH`, tune with `--interval` and `--db`. The `SpecGuardianDaemon`
  previously had zero callers; this gives it its first real entry point (#811, #823).
- **Enterprise CLI wiring** (Phase 13): `cherenkov enterprise` commands now wire the real
  `cherenkov/enterprise/` modules — SAML 2.0/SSO configuration, RBAC role assignment,
  org management, audit-log export, and SOC2 compliance reports — instead of the
  `"""Placeholder"""` stubs that shipped in v1.2.0 (#810, #824).
- **MCP agent tools**: check-suite, verify, and generate are exposed as agent-invokable
  MCP tools for IDEs/autonomous agents (#812, #821).
- **MCP registry manifest**: `manifest.json` + publish instructions ready for submission
  to the official MCP registry (#792).
- **5-Workspace UI/UX revamp (M1 prep)**: Overview, Author & Generate, Triage, Coverage &
  Certification, and Knowledge hubs; FastAPI backend wiring; a FastAPI SPA catch-all
  route; and a Playwright E2E suite (2e66658). The cold-run onboarding journey now
  survives end-to-end (session_a_zero_to_hero).
- **Scope filters**: `validate` accepts a `--tests` filter and OpenAPI 3.0.x patch
  versions (#829).
- **Dual AI routing consolidation**: the routing-layer analysis proposes a single
  tier-aware router, retiring the duplicate path (#815, #820).

### Fixed

- **Technical-debt pass** (architecture review, #832): FTS5 query construction in
  `knowledge/adapters/sqlite_repository.py` and `memory/adapters/sqlite_memory.py`
  now joins on the FTS shadow-table `rowid` (avoiding a full-table scan) and escapes
  embedded quotes via a shared helper.
- **Generate persistence**: test generation persists one distinct file per scenario
  (#828).
- **SDD runtime**: `agent_sync` MemSearch `workspace_dir` API mismatch repaired
  (c7b2008).
- **OpenAPI version accept**: validate accepts Swagger 2.0 and OpenAPI 3.0.x patch
  versions (#829).
- **M1 friction**: resolve friction bugs across tests and UI automation (6c7335b).

### Certification

- **Main certified green**: 2064 passed / 2 failed. The 2 failures
  (`test_verify_cmd.py`, mock drift vs E0.5i `known_identifiers`/`allow_mutations`
  kwargs) are pre-existing and tracked as **#819** (D7 — agents do not modify tests).
- **UI build verified**: `vite` output matches the committed dist hashes; no frontend
  regression.

### Notes

- The malformed `v.1.1.1` tag was corrected to `v1.1.1`. Release tags are now cut
  through release-please (via the `release-please--branches--main` branch) to avoid a
  repeat of the stray-dot breakage.
- **PAT expiry**: the maintainer's `gh` PAT expired mid-session (patronizing GitHub
  Releases still works via SSH); renew `~/.config/gh/hosts.yml` to restore `gh`/REST
