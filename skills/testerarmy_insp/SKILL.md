# TesterArmy Inspiration Skill

This skill provides a TesterArmy‑like CLI surface for CHERENKOV projects.

## Installation
```bash
npx skills add moaidmoatasem/cherenkov-qa --path skills/testerarmy_insp
```

## Usage
The skill adds a `testerarmy` command group with sub‑commands for projects, environments, tests, runs, and documentation.

See `cherenkov/cli/commands/testerarmy.py` for the full command list.
