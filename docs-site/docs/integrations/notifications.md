# Slack & Teams Notifications

CHERENKOV can send notifications to **Slack**, **Microsoft Teams**, and generic **webhook endpoints** when conformance events occur.

## Configuration

Configure notification endpoints in `cherenkov.toml`:

```toml
[notifications]
slack_webhook = "${SLACK_WEBHOOK_URL}"
teams_webhook = "${TEAMS_WEBHOOK_URL}"

[notifications.triggers]
on_drift = true           # Notify when spec drift is detected
on_gate_fail = true       # Notify when CI gate fails
on_release = true         # Notify on new release
```

## Slack Setup

1. Create an **Incoming Webhook** in your Slack workspace:
   - Go to `https://api.slack.com/apps` → Create New App → Incoming Webhooks
   - Select the channel where alerts should appear
   - Copy the webhook URL

2. Set the webhook URL as an environment variable:

```bash
export SLACK_WEBHOOK_URL="https://hooks.slack.com/services/T00/B00/xxx"
```

3. Run CHERENKOV — drift events will post to your Slack channel:

![Slack notification example](https://via.placeholder.com/600x200?text=Slack+Drift+Alert+Example)

## Microsoft Teams Setup

1. In your Teams channel, click **"..." → Connectors → Incoming Webhook → Configure**
2. Name the webhook and copy the URL
3. Set the webhook URL:

```bash
export TEAMS_WEBHOOK_URL="https://outlook.office.com/webhook/xxx"
```

## Generic Webhook

Any HTTP endpoint can receive CHERENKOV notifications:

```toml
[notifications]
webhook_url = "${CUSTOM_WEBHOOK_URL}"
```

The payload format:

```json
{
  "event": "drift_detected",
  "timestamp": "2026-06-29T12:00:00Z",
  "spec": "api.yaml",
  "target": "http://localhost:8000",
  "drift_count": 1,
  "findings": [
    {
      "endpoint": "GET /pets/{petId}",
      "expected": 200,
      "actual": 404,
      "evidence": "Field 'name' required but missing in response"
    }
  ]
}
```

## CI/CD Integration

In CI pipelines, use the `--output` flag to generate reports that notifications can reference:

```bash
cherenkov validate --spec api.yaml --target http://localhost:8000 --fail-on-drift
```

When drift is detected and exit code `1` is returned, your CI system can trigger its own notification via Slack/GitHub/email using the JUnit XML or SARIF reports generated by `--output ./reports`.
