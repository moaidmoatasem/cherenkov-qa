# Release Notes: CHERENKOV-QA v1.1.2

**Date:** 2026-07-31

## What's New Since v1.1.1

### Added

- **Unprobed-endpoint reporting** — `cherenkov verify` now lists every operation probe planning produced nothing for, with the real reason, before running. A zero-probe endpoint contributes no divergences, so a clean exit code previously implied coverage that never happened.
- **`RecordingProxy`** — a forwarding HTTP proxy that records what a test suite actually receives from a live target, feeding a record-then-perturb audit that needs no known-honest baseline suite.
- **`synthesize_mutant_battery()`** — emits one mutant per failure axis (status, single-value, enum, missing-field) plus a conforming control, so a test's failure is attributable to a specific weak assertion.

### Fixed

- **Soundness fix**: `verify` could report a clean run on an endpoint it never probed, when a path parameter was declared once on the PathItem and inherited by every operation beneath it (a legal OpenAPI 3.x form). 11 regression tests added.
- **Misleading gate skip message** — the mutant-synthesis skip reason now names the real cause instead of a generic "no documented success response."
- **Hanging unit test** fixed — a mock that mocked nothing was opening a live LLM connection.

### Known issues (resolved in v1.2.0)

- Release tags were inconsistent with the package version at this point in time — `pyproject.toml` declared `1.1.1` while the tag list already contained `v1.2.0` and a malformed `v.1.1.1`. See the [v1.2.0 release notes](v1.2.0.md).
