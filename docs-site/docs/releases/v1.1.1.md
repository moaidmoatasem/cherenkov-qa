# Release Notes: CHERENKOV-QA v1.1.1

**Date:** 2026-06-29 **Tag:** `v.1.1.1`

## What's New Since v1.1.0

v1.1.1 delivers 6 Claude Code-inspired enhancement phases (CC-1 through CC-6), 7 core platform phases (Phases 9-15), and numerous fixes.

### Claude Code-Inspired Enhancements

- **CC-1 (Auto-Memory + Hooks)**: SQLite FTS5 memory engine, HookRegistry with 10 events, SubprocessHookExecutor. ADR-011, ADR-012.
- **CC-2 (Multi-Agent Conductor)**: Fan-out/fan-in orchestration over MCP mesh.
- **CC-3 (MCP Ecosystem)**: Marketplace, push events, JWT auth, 5 integrations.
- **CC-4 (Scheduling + Routines)**: APScheduler, web UI, GitHub webhook trigger.
- **CC-5 (Remote Control + Teleport)**: Session snapshots, QR-code join, remote runners.
- **CC-6 (CLI Composability)**: `--json`/`--quiet` on all commands, pipe mode, completions.

### Platform Phases

- **Phase 9**: Semantic Memory — MemSearch SDD integration.
- **Phase 10**: CI/CD Native — Jenkins Shared Library.
- **Phase 11**: VS Code Extension — full wiring.
- **Phase 12**: gRPC Support — Buf Schema Registry.
- **Phase 13**: Drift Reconciliation — L2 maker/checker.
- **Phase 14**: Eval Pipeline — generate→grade→compare→optimize.
- **Phase 15**: Synthetic Suite Generation — STORM-inspired multi-persona.

### New CLI Commands

- `cherenkov demo` — 60-second offline onboarding
- `cherenkov drift` — spec-drift CLI with reconciliation
- `cherenkov report` — divergence JSON summary + diff
- `cherenkov check-suite` — AI cheating detection
- `cherenkov enterprise` — enterprise-tier operations

### Other

- JWT + RBAC auth layer across all routes
- Public documentation site (Material for MkDocs, GitHub Pages)
- Coverage gap reporting (`--coverage-report`)
- 8 P0 fixes across security, code quality, stability
- Windows WSL SQLite UNC path handling
