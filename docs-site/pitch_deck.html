Principle · Slide 2 of 10

The OpenAPI Spec is
the Single Source of Truth

One invariant. Zero exceptions.
  • Spec-derived: expected HTTP status comes from OpenAPI, never hardcoded by the LLM
  • 6-gate pipeline: deterministic checks catch AI hallucinations before tests hit disk
  • Local-first: qwen2.5-coder:7b via Ollama — your schemas never leave your machine
  • D7 invariant: validation suggests fixes but never auto-edits your test code

Live Demo · Slide 4 of 10

Spec In. Playwright Tests Out.

Generate spec-derived Playwright tests via local LLM $ cherenkov generate --spec petstore.json --output-dir tests/ # 4.   • Zero config to start — `cherenkov.toml` auto-generated with local-first defaults

  • Every assertion traceable to a specific field or status code in the spec
